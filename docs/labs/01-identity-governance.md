# Lab 01 — Identity and governance

## Objectives

- Create Entra users and groups in a disposable lab tenant when available.
- Compare directory roles with Azure RBAC roles.
- Assign least-privilege access at resource-group scope.
- Deploy and test the required-tag policy.
- Verify locks, tags, budgets and effective access.

## Evidence

Record redacted CLI output for role assignments, the policy assignment, a denied untagged resource and a successful tagged resource. Never commit tenant identifiers, emails, tokens or credentials.
